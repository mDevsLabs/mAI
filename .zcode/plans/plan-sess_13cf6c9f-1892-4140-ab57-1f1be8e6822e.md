## 2. Backend API — `models.ts` (racine, Val Town)
- **`GET /v1/models`** : injection de mai/mai-2 et mai/mai-2-mini en tête de liste (format OpenRouter, `owned_by: "mDevsLabs"`, maxContext 1M), **avant** le filtre `:free` → visibles pour tous les plans.
- **`POST /v1/chat/completions`** :
  - Bloc `isMaiLocal` réorganisé : `mai/mai-2` → remappage vers `minimax/minimax-m3` ; `mai/mai-2-mini` → `deepseek/deepseek-v4-flash-0731` avant l'appel OpenRouter ; `mai-1`/`mai-1-light` → erreur dédiée "modèle déprécié, non disponible" ; les autres `mai-*` → message existant "exécution locale" (inchangé).
  - Gating plans : exemption du filtre `:free` pour les ids `mai/` (disponibles tous plans, quotas hebdo inchangés).
  - Même remappage appliqué aux proxys `/v1/messages` (Anthropic) et Gemini pour cohérence.
  - **Erreurs OpenRouter** : si le modèle mappé renvoie une erreur → réponse à l'utilisateur : `Code : {CODE} - mAI est indisponible.` (CODE = code d'erreur upstream), style d'erreur adapté à chaque route.
- **`GET /v1/models/mai`** : renvoie `cloud`, `usable_in_cloud_chat: m.cloud`, sans `version`, avec les 10 modèles (dépréciés inclus).
