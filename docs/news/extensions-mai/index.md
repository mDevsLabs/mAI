# Lancement des extensions mAI pour VS Code et navigateurs web

L'écosystème **mAI** s'enrichit avec la mise à disposition de deux extensions dédiées, conçues pour intégrer l'assistance d'intelligence artificielle au plus près des flux de travail professionnels.

---

## Extension mAI pour Visual Studio Code

Développée pour les environnements de développement, l'extension **mAI pour Visual Studio Code** permet d'interagir avec votre modèle local directement depuis votre éditeur.

### Caractéristiques :
- **Complétion contextuelle** : Suggestions de code rapides basées sur votre contexte de travail.
- **Panneau latéral interactif** : Analyse d'architecture, révision de code et assistance au refactoring sans interruption de session.
- **Installation directe** : Décompressez l'archive et placez le dossier dans `.vscode/extensions`.

- **Télécharger l'extension VS Code** : [mAI-VSCode.zip](https://upload.fs.fr/ObQWvEwYTk.zip)
- **Consulter le guide d'installation VS Code** : [Documentation VS Code](/docs?doc=guide-extension-vscode)

---

## Extension mAI pour navigateurs web

L'extension mAI pour navigateur web permet d'analyser, synthétiser et extraire des informations directement depuis vos pages de consultation.

### Compatibilité et fonctionnalités :
- **Compatibilité étendue** : Fonctionne sur les navigateurs basés sur Chromium et les standards web actuels.
- **Optimisation** : Prise en charge ciblée pour **Microsoft Edge** et **Google Chrome**.
- **Déploiement simple** : Activez le mode développeur dans la page de gestion des extensions de votre navigateur et chargez l'archive décompressée.

- **Télécharger l'extension Navigateur** : [mAI-Web.zip](https://upload.fs.fr/Zn7FIHWR6M.zip)
- **Consulter le guide d'installation Navigateur** : [Documentation Navigateur](/docs?doc=guide-extension-navigateur)
