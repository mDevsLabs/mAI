# mAI-1.5-Apex 🏔️

**mAI-1.5-Apex** représente le modèle haut de gamme de la génération **mAI-1.5**. Avec ses 9 milliards de paramètres, il combine une puissance de calcul de premier ordre, une **vision multimodale de haute précision**, un **raisonnement poussé (thinking)** et la gestion complète des **appels de fonctions (tools)**.

> **Objectif** : Offrir des performances de niveau Flagship en local pour la résolution de problèmes complexes, le développement logiciel avancé et l'analyse de données multimodales souveraines.

---

## ⚙️ Spécifications clés

- **Taille** : 9 milliards de paramètres (9B).
- **Contexte** : Fenêtre de contexte native de **256K tokens**.
- **Vision** : Traitement haute fidélité des visuels et schémas complexes.
- **Raisonnement (Thinking)** : Capacités avancées d'analyse pas à pas et de logique.
- **Appels d'outils (Tools)** : Interfaçage natif avec des outils, scripts et bases de données.

---

## ✨ Fonctionnalités

- 🏔️ **Performances Flagship** : Raisonnement de haute précision adapté aux cas d'usage industriels et complexes.
- 📸 **Vision Multimodale Avancée** : Analyse minutieuse d'images haute résolution, de diagrammes et d'architectures.
- 🧠 **Mode Thinking Intégré** : Évaluation d'hypothèses et résolution guidée de problèmes ardus.
- 🧰 **Support d'Outils (Function Calling)** : Exécution d'actions structurées et intégration dans des agents autonomes.
- 💻 **Ingénierie Logicielle** : Refactoring de code, conception d'architectures, audit et débogage approfondi.
- 🔎 **RAG Haute Densité** : Calibré pour les pipelines de recherche d'information complexes à fort volume.
- 🔐 **Sécurité & Souveraineté** : Modèle 100% exécutable hors-ligne sans fuite de données.

---

## 🚀 Guide d'installation rapide

### 1. Installer Ollama

Téléchargez et installez Ollama depuis le site officiel :

[https://ollama.com/download](https://ollama.com/download)

### 2. Exécuter le modèle

Exécutez le modèle dans votre terminal :

```bash
ollama run mDevsLabs/mAI-1.5-Apex
```

### 3. Télécharger depuis Hugging Face

```bash
hf download mDevsLabs/mAI-1.5-Apex
```
