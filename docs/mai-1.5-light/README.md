# mAI-1.5-Light ⚡

**mAI-1.5-Light** est l'assistant IA local ultra-rapide et multimodal de la nouvelle génération **mAI-1.5**. Conçu pour s'exécuter avec une légèreté maximale via **Ollama**, ce modèle intègre la **vision multimodale**, la capacité de **raisonnement (thinking)** ainsi que le support natif des **appels d'outils (tools / function calling)**.

> **Objectif** : Fournir une IA locale agile et réactive pour les postes individuels et laptops, sans sacrifier l'intelligence et la souveraineté de vos données.

---

## ⚙️ Spécifications clés

- **Taille** : 4 milliards de paramètres (4B).
- **Contexte** : Fenêtre de contexte native de **256K tokens**.
- **Vision** : Traitement avancé et compréhension d'images, cartes, schémas et captures d'écran.
- **Raisonnement (Thinking)** : Réflexion logique approfondie avant la génération de réponse.
- **Appels d'outils (Tools)** : Exécution de fonctions et intégration dynamique aux API externes.

---

## ✨ Fonctionnalités

- ⚡ **Vitesse & Légèreté** : Modèle ultra-optimisé (4B) avec réponse quasi-instantanée sur PC portable.
- 📸 **Vision Multimodale** : Analyse détaillée de visuels, documents numérisés et graphiques.
- 🧠 **Modèle de Raisonnement (Thinking)** : Capacité de pensée critique et d'explication étape par étape.
- 🛠️ **Function Calling & Tools** : Interfaçage direct avec des scripts locaux et des API d'entreprise.
- 💻 **Développement logiciel** : Assistant de code fluide, génération de scripts et correction de bugs.
- 🌍 **Support multilingue** : Français, anglais, espagnol, allemand, italien, japonais, etc.
- 🔐 **Confidentialité totale** : Exécution 100% locale, sans aucune dépendance au cloud.

---

## 🚀 Guide d'installation rapide

### 1. Installer Ollama

Téléchargez et installez Ollama depuis le site officiel :

[https://ollama.com/download](https://ollama.com/download)

### 2. Exécuter le modèle

Dans votre terminal, lancez la commande :

```bash
ollama run mDevsLabs/mAI-1.5-Light
```

### 3. Télécharger depuis Hugging Face

```bash
hf download mDevsLabs/mAI-1.5-Light
```
