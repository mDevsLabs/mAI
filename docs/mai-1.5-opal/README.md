# mAI-1.5-Opal 💎

**mAI-1.5-Opal** est le modèle équilibré ultime de la génération **mAI-1.5**. Avec ses 27 milliards de paramètres, il offre un équilibre exceptionnel entre capacité de raisonnement, **vision multimodale**, **mode thinking** et **appels de fonctions (tools)** sur des infrastructures locales ou serveurs.

> **Objectif** : Proposer le parfait compromis entre intelligence élevée de niveau chercheur et fluidité d'exécution pour les projets d'entreprise, la rédaction technique et la programmation.

---

## ⚙️ Spécifications clés

- **Taille** : 27 milliards de paramètres (27B).
- **Contexte** : Fenêtre de contexte native de **256K tokens**.
- **Vision** : Traitement et interprétation multimodale complète.
- **Raisonnement (Thinking)** : Logique formelle, synthèse documentaire et réflexion approfondie.
- **Appels d'outils (Tools)** : Support d'outils et d'API externes hautement fiable.

---

## ✨ Fonctionnalités

- 💎 **Intelligence Supérieure (27B)** : Conçu pour la génération de contenu complexe et la logique avancée.
- 📸 **Vision Multimodale** : Analyse et extraction de données d'images, de documents administratifs et techniques.
- 🧠 **Raisonnement Thinking** : Capacité à décomposer des problèmes complexes en sous-étapes logiques.
- 🛠️ **Function Calling (Tools)** : Automatisation fiable de requêtes système, requêtes SQL et appels API.
- 📄 **Analyse de Longs Documents** : Traitement de contextes jusqu'à 256K tokens pour la recherche documentaire.
- 🌍 **Multilingue Avancé** : Maîtrise naturelle de dizaines de langues et de jargons spécialisés.
- 🔐 **Souveraineté des Données** : Exécution locale privée et sécurisée sans dépendance cloud.

---

## 🚀 Guide d'installation rapide

### 1. Installer Ollama

Téléchargez et installez Ollama depuis le site officiel :

[https://ollama.com/download](https://ollama.com/download)

### 2. Exécuter le modèle

Exécutez le modèle dans votre terminal :

```bash
ollama run mDevsLabs/mAI-1.5-Opal
```

### 3. Télécharger depuis Hugging Face

```bash
hf download mDevsLabs/mAI-1.5-Opal
```
