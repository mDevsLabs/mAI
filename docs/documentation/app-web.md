# Web - Application d'IA en ligne 

**Web** est l'application d'IA en ligne officielle de l'écosystème **mAI**. Conçue pour offrir une interface utilisateur directe, épurée et sans configuration superflue, elle permet d'interagir immédiatement avec l'intelligence artificielle mAI et l'ensemble de nos modèles.

- **Statut** : **Alpha**
- **Dépôt GitHub** : [https://github.com/mDevsLabs/Web](https://github.com/mDevsLabs/Web)

---

## Fonctionnalités Principales

- **Discussion Directe & Fluide** : Dialogue en temps réel avec streaming de tokens ultra-rapide.
- **Accès Multi-Modèles** : Basculez entre les modèles de pointe de la gamme mAI (mAI-1.5-Light, mAI-1.5-Apex, mAI-1.5-Opal) et les modèles partenaires.
- **Rendu Markdown & Code Enrichi** : Coloration syntaxique, rendu mathématique LaTeX et prévisualisation instantanée.
- **Zéro Configuration** : Accessible directement depuis n'importe quel navigateur moderne, sans installation requise.

---

## Accès & Démarrage

Rendez-vous simplement sur l'interface web pour démarrer une nouvelle conversation avec mAI. Vos sessions et préférences sont synchronisées avec votre compte unifié mAI.
